# Observability & Monitoring Plan
## Samkhya Yoga Agentic Trader — Production Monitoring Specifications

**Generated:** 2026-02-15
**Document Version:** 1.0
**Monitoring Philosophy:** Business metrics + System metrics + Philosophical coherence tracking

---

## Executive Summary

This plan defines comprehensive observability for the Samkhya Yoga trading system, covering:
1. **Business Metrics:** Trade outcomes, karma learning, strategy performance
2. **System Metrics:** Latency, throughput, error rates, resource utilization
3. **Philosophical Metrics:** Guna balance, Dasha transitions, Rahu Kala adherence
4. **Compliance Metrics:** MiFID II coverage, audit trail completeness

**Stack:**
- **Metrics:** Prometheus + Pushgateway
- **Visualization:** Grafana (8 dashboards)
- **Alerting:** Alertmanager + PagerDuty
- **Tracing:** Jaeger (distributed tracing)
- **Logging:** ELK Stack (Elasticsearch, Logstash, Kibana)

## 2. Grafana Dashboard Specifications

### Dashboard 1: OODA Loop Performance

**Purpose:** Monitor OODA cycle health and latency
**Refresh:** 10 seconds
**Panels:**

1. **OODA Cycle Duration (Heatmap)**
   - Query: `histogram_quantile(0.95, rate(ooda_cycle_duration_seconds_bucket[5m]))`
   - Visualization: Heatmap
   - Y-axis: Duration (seconds)
   - X-axis: Time

2. **OODA Phase Breakdown (Stacked Area)**
   - Queries:
     - Observe: `rate(ooda_cycle_duration_seconds_sum{phase="observe"}[5m])`
     - Orient: `rate(ooda_cycle_duration_seconds_sum{phase="orient"}[5m])`
     - Decide: `rate(ooda_cycle_duration_seconds_sum{phase="decide"}[5m])`
     - Act: `rate(ooda_cycle_duration_seconds_sum{phase="act"}[5m])`

3. **OODA Error Rate (Graph)**
   - Query: `rate(ooda_phase_errors_total[5m])`
   - Alert Threshold: > 0.1 errors/sec

4. **Cycles Completed (Counter)**
   - Query: `increase(ooda_cycle_duration_seconds_count[1h])`

### Dashboard 2: Navagraha State Visualization

**Purpose:** Real-time view of planetary positions and guna state
**Refresh:** 1 minute
**Panels:**

1. **Planetary Positions (Polar Chart)**
   - Custom visualization showing 9 planets on zodiac wheel
   - Data: `planet_longitude_degrees` for each planet

2. **Guna Ratios (Pie Chart)**
   - Queries:
     - Sattva: `guna_ratio_sattva`
     - Rajas: `guna_ratio_rajas`
     - Tamas: `guna_ratio_tamas`

3. **Current Dasha (Stat Panel)**
   - Query: `current_dasha_planet`
   - Display: Planet name + remaining time

4. **Rahu Kala Status (Alert Panel)**
   - Query: `rahu_kala_active`
   - Color: Red when active, green when inactive

5. **Navagraha Calculation Performance (Graph)**
   - Query: `histogram_quantile(0.95, rate(navagraha_calculation_duration_seconds_bucket[5m]))`
   - Target Line: 500ms (cold), 50ms (cached)

### Dashboard 3: Trading Performance

**Purpose:** Monitor trade outcomes and strategy effectiveness

### Error Budgets

**Monthly Error Budget (99.9% availability):**
- Allowed downtime: 43.2 minutes per month

**Burn Rate Alerts:**
- **Fast burn (1 hour):** Consuming > 5% of monthly budget in 1 hour
- **Slow burn (6 hours):** Consuming > 10% of monthly budget in 6 hours

## 4. Alert Rules

### Critical Alerts (PagerDuty)

```yaml
# alertmanager.yml
groups:
  - name: critical_trading
    interval: 30s
    rules:
      - alert: MiFIDIIAuditCoverageNotComplete
        expr: mifid2_audit_coverage_ratio < 1.0
        for: 1m
        annotations:
          summary: "MiFID II audit trail incomplete"
          description: "Audit coverage is {{ $value }}, must be 1.0"
        labels:
          severity: critical

      - alert: CircuitBreakerCascade
        expr: sum(circuit_breaker_state == 2) >= 3
        for: 2m
        annotations:
          summary: "Circuit breaker cascade detected"
          description: "{{ $value }} circuits are OPEN"
        labels:
          severity: critical

      - alert: OODALoopStalled
        expr: rate(ooda_cycle_duration_seconds_count[5m]) == 0
        for: 5m
        annotations:
          summary: "OODA loop not executing"
        labels:
          severity: critical

      - alert: EphemerisCalculationFailing
        expr: rate(navagraha_calculation_duration_seconds_count[5m]) == 0
        for: 3m
        annotations:
          summary: "Navagraha calculations failing"
        labels:
          severity: critical

  - name: high_priority
    interval: 1m
    rules:
      - alert: HighOODALatency
        expr: histogram_quantile(0.95, rate(ooda_cycle_duration_seconds_bucket[5m])) > 5.0
        for: 5m
        annotations:
          summary: "OODA cycle latency exceeds 5 seconds"
        labels:
          severity: high

      - alert: LowCacheHitRate
        expr: navagraha_cache_hit_rate < 0.6
        for: 10m
        annotations:
          summary: "Cache hit rate below 60%"
        labels:
          severity: high

      - alert: PositionLimitApproaching
        expr: position_limit_utilization > 0.9
        for: 1m
        annotations:
          summary: "Position limit 90% utilized for {{ $labels.symbol }}"
        labels:
          severity: high

  - name: warnings
    interval: 5m
    rules:
      - alert: WinRateBelowTarget
        expr: win_rate < 0.45
        for: 1h
        annotations:
          summary: "Win rate below 45% for {{ $labels.strategy }}"
        labels:
          severity: warning

      - alert: AgentPranaLow
        expr: agent_prana_level < 20
        for: 15m
        annotations:
          summary: "{{ $labels.element }} agent prana below 20"
        labels:
          severity: warning
```

## 5. Logging Strategy

### Structured Logging Format

```python
import structlog
import sys

logger = structlog.get_logger()
logger.configure(
    processors=[
        structlog.stdlib.add_log_level,
        structlog.stdlib.add_logger_name,
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.StackInfoRenderer(),
        structlog.processors.format_exc_info,
        structlog.processors.JSONRenderer()
    ],
    wrapper_class=structlog.stdlib.BoundLogger,
    context_class=dict,
    logger_factory=structlog.stdlib.LoggerFactory(),
    cache_logger_on_first_use=True,
)

# Usage
logger.info(
    "trade_executed",
    trade_id="12345",
    symbol="BTC/USDT",
    direction="long",
    pnl_usd=150.50,
    strategy="TrendFollowing",
    dasha="Mars",
    guna_dominant="rajas",
    navagraha_state_id="state-abc123"
)
```

### Log Levels

- **DEBUG:** Detailed flow, cache hits/misses, guna calculations
- **INFO:** Trade decisions, OODA phase completions, parameter adjustments
- **WARNING:** Low prana, cache misses, retry attempts, Rahu Kala blocks
- **ERROR:** Failed API calls, calculation errors, validation failures
- **CRITICAL:** Circuit breaker cascade, MiFID II violations, system halt
