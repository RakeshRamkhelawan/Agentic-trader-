Getting JSON serialization errors?
  → This is fixed in the updated verify_mind_body_flow.py
  → Make sure you're using the latest version

Getting "Shared memory already exists"?
  → A previous process didn't clean up
  → Restart your computer OR run cleanup script

Services failing to start?
  → Check logs - all services log to stdout
  → Enable debug logging in settings.py
