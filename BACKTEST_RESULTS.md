## Strategy Details

### Simple Momentum Strategy
```python
if close > previous_close * 1.01:  # 1% up
    action = "buy"
elif close < previous_close * 0.99:  # 1% down
    action = "sell"
else:
    action = "hold"
```

- Position size: Fixed 0.1 units per trade
- No leverage used
- Paper trading mode (no real orders)
